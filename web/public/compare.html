같은 조건으로 비교하는 방법

  1. 먼저 1번의 첫 화면을 5초만 보고, 무엇을 해 주는 서비스인지 한 문장으로 적어 보세요. 2번·3번도 똑같이 해요.
  2. 아래 가상 프로필 하나를 골라 1번에서 처음부터 끝까지 입력하고 결과를 봐요. 같은 답을 2번·3번에도 입력해요.
  3. 결과에서 숫자의 뜻, 걱정할 부분과 유지할 부분, 할 일을 찾아보세요. 저장·기록·진료용 요약도 눌러 봐요.
  4. 세 버전의 기록은 서로 따로 저장돼요. 건강정보는 서버로 보내지 않아요. 실제 내 정보 대신 가상 프로필을 써도 돼요.

비교할 때 볼 질문 4개

  1. 무엇을 해주는 서비스인지 더 빨리 이해한 쪽은?
  2. 결과 숫자의 뜻을 더 쉽게 이해한 쪽은?
  3. 걱정할 부분과 유지할 부분을 더 명확히 알 수 있는 쪽은?
  4. 더 편하고 덜 피곤한 쪽은?

답은 ‘1번 / 2번 / 3번 / 비슷함’과 그렇게 느낀 이유 한 줄이면 충분해요.
