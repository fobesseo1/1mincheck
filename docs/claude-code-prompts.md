# 1분체크 (1mincheck): Claude Code 지시문 (모바일 앱 → 랜딩 페이지 → 홍보 영상)

영상(Jason Lee, 2026-09-29)의 흐름을 1분체크에 맞게 바꾼 버전입니다. 계산 함수는 이미 테스트까지 끝난 상태로 넘기기 때문에, Claude Code는 **디자인과 화면에만 집중**하면 됩니다.

## 0. 준비

폴더 구조 (바탕화면 `1mincheck` 폴더에 이미 넣어 둠):

```
1mincheck/
├─ docs/
│  ├─ spec.md                  ← 기획·근거·함수모형 (1분체크_기획_근거_함수모형.md)
│  └─ claude-code-prompts.md   ← 이 지시문
└─ engine/                     ← 계산 엔진 (테스트 20개 통과)
   ├─ README.md
   ├─ package.json
   ├─ tsconfig.json
   ├─ src/engine.ts
   ├─ src/prevalence.json
   └─ test/engine.test.ts
```

1. Claude Code를 `1mincheck` 폴더에서 실행합니다.
2. **디자인 레퍼런스를 하나 고릅니다.** 영상처럼 디자인 시스템 정리 사이트에서 마음에 드는 앱의 디자인 시스템 페이지 URL을 가져옵니다.
   - 건강 앱이라면 차분하고 신뢰감 있는 핀테크·헬스 계열이 잘 어울립니다.

## 1단계: 모바일 앱 디자인 (`/design`)

```
/design

"1분체크"(영문 1mincheck)라는 iOS 앱을 디자인해줘. 질문 몇 개에 답하면 나이·성별이 같은 한국인 통계와 비교해서
12가지 건강 항목의 확률을 보여주는 건강 셀프체크 앱이야.

- 기능·문항·분기·결과 화면은 docs/spec.md §5(입력)와 §7(결과)을 그대로 따라줘.
- 계산은 engine/src/engine.ts의 runAll()과 whatIf()만 호출해. 계산 로직과 수치는 절대 수정하지 마.
  샘플 화면의 숫자도 반드시 이 함수를 실제로 실행한 결과를 써줘.
  (예시 사용자: 49세 여성, 160cm, 62kg, 허리 81.3cm, 비흡연·비음주·운동함·폐경 전)
- 필요한 화면:
  온보딩 → 기본정보 → 수면·마음·소화·식생활 모듈(분기형) → 결과 요약
  → 항목 상세(100명 중 N명 아이콘 그림, 동년배 비교, 근거 논문 링크, 다음 할 일)
  → what-if 슬라이더(체중·허리·흡연·음주·운동) → 기록 비교
- 톤: 겁주지 않고 차분하게. 빨간 경고 대신 "관리하면 이만큼 줄어요"를 강조해줘.

디자인 언어와 폰트는 이 디자인 시스템을 참고해줘: <디자인 시스템 URL>
```

**만든 뒤 할 일**

- 화면을 직접 눌러 보며 확인합니다: `localhost로 띄워줘. 모든 버튼과 화면 이동이 동작하는지 확인하게.`
- 색을 바꿉니다: `디자인 언어는 유지하고 색 테마만 바꾸고 싶어. 건강 앱에 어울리는 색 조합 3가지를 위젯 미리보기로 보여줘.`
- 숫자가 맞는지 검증합니다: `화면에 표시된 모든 확률이 engine 함수의 실제 출력과 같은지 대조해줘.`

## 2단계: 랜딩 페이지

```
/design

1분체크 앱을 소개하는 랜딩 페이지를 만들어줘. docs/handoff.md와 앱 화면을 참고하고,
앱과 같은 디자인 언어·색·폰트를 써줘.

- 첫 화면: "1분이면 보는 내 몸의 확률". 바로 옆에서 나이·성별·키·몸무게를 넣으면
  engine으로 고혈압·당뇨·지방간 결과 3개가 즉시 나오는 미니 체험을 넣어줘.
- 섹션: 어떻게 계산하나(국민건강영양조사 + 한국인 논문, §2 원리) · 12개 항목 · what-if 애니메이션
  · 개인정보(서버 전송 없음) · 근거 자료 목록 · 자주 묻는 질문 · 앱 다운로드
- 움직임: 스크롤에 따라 100명 아이콘 그림이 채워지는 애니메이션, 허리 슬라이더를 움직이면 확률이 내려가는 데모.
- 이건 네 웹디자인 실력을 보여주는 포트폴리오라고 생각하고 최고 수준으로 만들어줘.
```

## 3단계: 홍보 모션그래픽 (20초)

영상에서 쓴 "런치 비디오" 스킬(영상 설명란 GitHub 링크)을 먼저 설치합니다.

```
<설치한 영상 스킬 명령> 1분체크 앱의 20초짜리 런치 영상을 만들어줘.
- 이 폴더에 있는 앱 화면·랜딩 페이지·로고·색을 그대로 써줘.
- 스토리: ① "내 몸, 숫자로 보면?" ② 질문에 답하는 장면 ③ 100명 아이콘이 채워지며 확률 등장
  ④ 허리 슬라이더를 움직이자 확률이 내려감 (71.9% → 28.9%, 지방간 예시 = engine 실제 출력)
  ⑤ "국민건강영양조사 · 한국인 논문 기반" ⑥ 1분체크 로고
- 네가 최고의 모션 디자이너라는 걸 보여줘.
```

- **먼저 장면표 받기:** 만들기 전에 `영상을 장면별로 먼저 나눠서 보여줘`라고 하면, 문구와 순서를 수정한 뒤 생성할 수 있습니다.
- **참고 영상 쓰기:** 마음에 드는 영상이 있으면 `이 영상을 프레임 단위로 보고 스타일을 참고해줘: <URL>`을 추가합니다.
