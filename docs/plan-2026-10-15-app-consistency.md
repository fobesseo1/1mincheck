# 앱 전체를 새 결과 화면에 맞추기 — 점검 결과와 계획 (2026-10-15)

기준: `docs/DESIGN.md`(2026-10-15 개정) = 새 결과 화면. 점검은 v3 사이트(localhost:5183)를 휴대폰 폭으로 직접 보고, 코드에서 같은 패턴이 쓰인 곳을 모두 찾아 대조했다.

## 1. 어긋난 곳 (화면별)

### 공통 틀 — 모든 화면에 영향 (가장 먼저)
| 어긋난 것 | 지금 | 기준 | 위치 |
|---|---|---|---|
| 바탕 | 연두 그라데이션(`Fields`) | 무채색 #f4f4f2 | `ui.tsx` AppShell, Inputs·Labs·Landing |
| 위 머리줄 | 유리 질감 원형 뒤로 버튼 + 가운데 제목·부제 | 흰 원형 버튼(그림자 없음) + 같은 글자 단계 | `ui.tsx` Nav, GlassButton |
| 아래 탭 막대 | 유리 알약 + 진초록 글자·렌즈 | 흰 알약, 고른 칸만 잉크 | `ui.tsx` TabBar |
| 주 버튼 | 라임 바탕 진초록 글자 | 잉크 바탕 흰 글자 52px | `components/ui/button.tsx` default |
| 카드 | 모서리 16px + 그림자 | 모서리 20px, 그림자 없음 | `components/ui/card.tsx` |
| 글자 단계 | heading-sm 28px · subheading 23px 등 다른 체계 | 24 · 19 · 17 · 15 · 14 · 13 · 12 · 11 | 여러 화면 |

### 입력 (`#/info`, `#/life` — Inputs.tsx)
- 제목을 회색+검정 두 색으로 나눔("먼저 몸 정보를 / 알려 주세요") → 한 색.
- 입력 숫자가 44–50px로 결과 화면 숫자(30px)보다 큼 → 숫자 30px + 단위 15px.
- 성별·흡연·술 선택에 진초록 칸, 술 양 −/+ 가 진초록 원 → 잉크 선택 칸, 회색 원 버튼.
- '다음' 라임 버튼 → 잉크 주 버튼.
- BMI 결과 칸이 진초록 상자 → 회색 옅은 칸 + 뱃지.

### 모든 항목 보기 (`#/all` — All.tsx) ★ 사용자 지적
- 큰 %(30px "2.4%")가 맨 앞 → 결과 화면처럼 "○○대 남성 중 N번째로 위험/안전 (100명 중)" + 위치 막대, 설명은 자세히 안으로.
- "또래 평균 약 3.9%보다 낮아요", "지금 가능성", "계산 대상 아님" 같은 말이 그대로 → 8장 문구 규칙으로.
- 빨간 긴 문단(지방간 '검사 필요' 설명 전체가 빨강) → 빨강은 뱃지·핵심 말만, 설명은 회색.
- 카드 하나에 항목이 세로로 길게 → 결과 화면의 '세 줄 카드' 모양으로 항목 줄을 늘어놓는다(당뇨·고혈압·고콜레스테롤·지방간·골다공증·체형·생활 체크).
- 링 그래프(`Ring`) → 쓰지 않음.

### 항목 상세 (`#/detail/:id` — Detail.tsx)
- 가운데 큰 "20.5%", "나와 비슷한 사람 100명 중 약 21명", 빨간 "또래 평균 14.2%보다 높아요(약 1.4배)" → 순위 문장 + 위치 막대 + 100명 중 N명 순서로, 배수는 뺀다.
- 사람 점 그림·구간 게이지·연령대 막대 등 그림이 여러 개 → 그림은 하나(위치 막대) + 필요하면 연령대 비교 하나.
- '점수는 이렇게 나왔어요'(당뇨만) → 고혈압·지방간도 같은 모양, 줄마다 이유 설명(이유 칩).

### 바꿔보기 (`#/whatif` — WhatIf.tsx)
- 결과 화면의 '생활을 바꾸면'과 **같은 일을 다른 방식**(엔진 %·%p, 진초록 상자, 라임 알약)으로 한다 → 화면을 없애고 결과 화면으로 보낸다. 판정 할 일의 `#/whatif` 링크도 함께 정리.

### 검진 풀이 (`#/labs`, `#/labs/result` — Labs.tsx)
- 입력: 그라데이션 바탕, 입력칸 모양이 결과 화면과 다름 → 무채색 + 숫자·단위 크기 규칙.
- 결과: 판정 머리 색 상자(빨강 띠·초록 바탕), '조금 주의' 회색 뱃지 등 → 세 줄 카드와 같은 줄 모양(뱃지 → 이름·수치 → 구간 막대 → 자세히).

### 기록 (`#/record` — Record.tsx)
- 라임 '체크 시작하기' 버튼, 그라데이션 → 잉크 버튼, 무채색.
- 비교 화면: 진초록 숫자 상자 → 결과 상자(지금/바꾸면 막대)와 같은 모양으로 '지난번/이번'.

### 진료용 요약 (`#/summary` — Summary.tsx)
- 라임 '인쇄·PDF로 저장' 버튼 → 잉크 버튼.
- 표 안의 %: 의사에게 보여 주는 문서라 %를 남길지 정해야 함(아래 '정할 것').

### 첫 화면 (Landing·LandingScenes·SpreadScene·MiniTrial)
- 진초록·라임은 결정된 예외(A안)라 그대로 둔다.
- 그러나 **결과를 보여 주는 장면이 예전 카드**(VerdictCard·PeerCardView·ChangeCard)와 %·"또래의 ○배"를 쓴다 → 새 부품(Todo·세 줄 카드·생활을 바꾸면)으로 교체.
- '10초 간단 체험'(MiniTrial)의 결과도 %·배수 → 세 줄 카드 모양.
- 소개 영상은 예전 화면 녹화 → 앱이 확정된 뒤 다시 만든다(기존 결정).

### 코드 정리
- `Results.tsx` 안에 예전 결과 카드(VerdictCard·PeerCardView·ChangeCard·LineBar·DragBar)가 남아 랜딩이 쓰는 중 → 랜딩 교체 후 삭제.
- `components/viz.tsx`(Dots·ZoneGauge·CountTo), `ui/zone-slider.tsx`, `body-character.tsx`(섞는 캐릭터)는 새 화면이 안 씀 → 다른 화면 교체 후 쓰는 곳이 없으면 삭제.
- `lib/overview.ts` 의 `big`·`sub`·`span` 칸은 지운 시안용 → 정리.
- 판정(`verdict.ts`)의 `sub` 문장은 새 화면이 안 씀, 할 일 `d`에 %가 들어 있음 → 판정 쪽에서 쉬운 말로 바꾸고 `plain()` 의존을 줄인다.

### 아직 없는 기능 (기존 계획 6장)
- 누구 것인지 고르기(나·엄마·오빠…)와 화면 위 이름표.
- 카톡 공유 카드(지금은 앱 주소·소개 문구만 보냄).

## 3. 결정 (2026-10-15, 사용자)
1. 진료용 요약은 **% 그대로**(모양만 앱과 같게).
2. 첫 화면도 **무채색**으로 바꾼다.
3. 바꿔보기 화면(`#/whatif`)은 **없애고** 결과 화면으로 보낸다(파일은 남김).
4. 순서: Claude 디자인 캔버스에 **모든 화면을 먼저 다 그리고** 사용자 확인 뒤 코드. 예전 데이터·코드 파일은 지우지 않는다.
5. 누구 것인지 고르기 + 카톡 공유 카드(8단계)는 **나중에**.

## 4. 진행 상황 (2026-10-15, 캔버스 확인 뒤 코드)
v3 코드에 옮긴 것 (커밋 전, 사용자 확인 대기):
- **공통 틀**: `index.css` 토큰 무채색(예전 brand·lime 이름은 남기고 값만 잉크·흰색·회색, 진초록은 `--color-forest`), 카드 20px·그림자 없음, 바탕 #f4f4f2. `ui.tsx` Nav 흰 원 뒤로 버튼, TabBar 흰 알약(고른 칸만 잉크, 유리·렌즈 없음), 진행 막대·제목 한 색. Button 주 = 잉크 52px, Badge 11px 알약, Segmented 잉크.
- **줄바꿈 버그**: `p, li, span { text-wrap: pretty }` 묶음 속성이 부모의 `nowrap`을 풀어 버려 '3번째로 / 위험'이 갈라졌음 → `text-wrap-style` 로 고침. 숫자 범위(2023–2025, 140/90)는 `nb()`로 붙임.
- **입력**: 기본정보 2×2 숫자 카드(30px+15px 붙여서, 허리 단위 알약, 인치 기본), BMI 흰 카드+뱃지. 생활: 술 양 회색 원 −/+, 맥주 단위 '캔'.
- **모든 항목 보기**(`All.tsx`): 결과 화면 세 줄(RowView) + 콜레스테롤·골다공증·체형을 같은 줄 모양, 앞으로 몇 년 안에(못 계산하면 '넣기'), 생활·검진 체크(결론은 문장 단위로만 나눔), 넣은 정보, 진료용 요약 링크. 링·배수 없음.
- **항목 상세**(`Detail.tsx`): 순위 문장+위치 막대 → 100명 중 N명, 왜 높을까(`overview.leversOf`: 하나만 바꾸면 100명 중 몇 명), 나이대별 또래 막대, 점수 내역, 다음에 할 일, 생활을 바꾸면 → 결과, 근거.
- **검진 풀이**(`Labs.tsx`·`Checkup.tsx`): 입력 칸 128px(숫자 22px+단위), 결과는 잉크 할 일 상자 + 개수 알약 + 줄 모양(뱃지 → 이름·수치 → 구간 막대 → 자세히). 주의 회색.
- **기록**(`Record.tsx`): 날짜 고르기(지금 잉크), 잉크 요약 상자(몸무게·좋아진 항목·허리 인치), 달라진 항목은 '100명 중 N명 → M명'·이전 빈 점/지금 색 점. 기록 없음·하나일 때 화면.
- **진료용 요약**(`Summary.tsx`): 무채색, % 그대로, 숨긴 설문 점수 칸 뺌, 문장·항목 단위 줄바꿈.
- **#/whatif·#/change** → `#/result` 로 돌려보냄(`WhatIf.tsx` 파일은 남김).
- **첫 화면**: 새 파일 `LandingV4.tsx`(예전 `Landing.tsx` 등은 남김). 어두운 무채색 첫 화면 + 기기 틀 속 결과 화면(실제 판정·세 줄), 또래 비교(RowView 그대로), 생활을 바꾸면(결과 화면 `Change` 그대로), 10초 체험(같은 체형 통계, '100명 중 N명 / 또래 평균'), 검진 풀이, 자주 묻는 질문.
- 확인: `tsc` 통과, 테스트 132개 통과, 빌드 성공, 375px에서 13개 화면 측정(가로 넘침 0, 숫자-단위 틈 0, 남은 줄넘김은 긴 한 문장이 단어 경계에서 넘어가는 곳뿐).

남은 것: 예전 부품 정리(7단계, 사용자 요청으로 파일은 지우지 않음), 누구 것인지 고르기·카톡 공유 카드(8단계, 나중에), 소개 영상 다시 만들기.
