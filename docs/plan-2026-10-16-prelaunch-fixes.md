# 출시 전 고칠 것 — 테스트 분석 반영 계획 (2026-10-16, 검토 2차 반영판)

근거: `Documents/Codex/2026-10-16/cja/outputs/1mincheck-출시전-테스트-분석.md`(운영 주소 탐색 테스트), 영상 작업 중 발견한 '허리 모름' 잘못 표시, 이 계획에 대한 검토 의견(같은 날).
항목마다 v3 코드에서 원인을 직접 확인했다. **계산식은 바꾸지 않는다.** 화면에 새로 들어갈 문구는 지어 넣지 않고 **시안(문구 후보)으로 먼저 확인**받는다.

## 원칙 (착수 전 확정)

1. **허리 원본값 유지** — 계산은 언제나 내부 원본 치수(cm, 사용자가 넣은 그대로 환산한 값)로 한다. 반올림은 화면 표시에만. 단위만 바꾸면 원본값·결과가 그대로여야 한다. 사용자가 숫자를 새로 넣을 때만 원본값이 바뀐다.
2. **허리 단위 표시** — 기본은 인치(정수), 사용자가 cm를 고르면 그 사람 화면은 cm(기존 규칙). 결과·요약 문장의 허리 단위도 사용자가 고른 단위를 따른다.
3. **'모름'은 상태로 다룬다** — 빈 칸 = 모름. 모르는 항목이 무엇인지 결과까지 전달되고, 안내 이유는 실제 모르는 항목과 일치해야 한다.
4. **숫자마다 대상 집단·기간·산출 방식이 화면 이름과 맞아야 한다** — 이름만 바꾸지 않는다. 대상이 다르면(예: 전체 성인 평균) '또래 평균'으로 부르지 않는다.
5. **이번 수정 완료 ≠ 출시 검증 완료** — 아래 '이번 수정의 완료 기준'과 '출시 전 남은 검증'을 따로 본다.

### 기준이 화면 이름과 맞지 않는 곳

1. **N5 지방간 '또래 평균'** — 실제는 성별 전체 성인, 2016–18, 다른 판정 기준. '같은 또래는 평균', '40대 남성 평균'으로 부르면 안 됨. 상세 나이대 막대도 모든 나이가 같은 값이라 의미가 없음.
2. **N6 바꿔보기 '혈압이 높은 사람'** — 진단받고 약 먹는 사람까지 포함한 실측 비율. N2(진단 안 받은 사람의 추정 가능성)와 대상이 달라 26명 ≠ 19명. 화면에 대상 차이가 안 보임.
3. **N1과 N3의 나이 범위** — 순위는 나이 ±5세, 이름표·평균은 10년 나이대('40대 남성'). 47세는 42–52세와 비교되는데 '40대 남성 중'이라고 표시.
4. **N1 '번째로 위험'** — 실제로 아픈 순서가 아니라 추정 가능성의 순위. 혈압을 넣은 사람도 '혈압 모름' 분포와 비교됨.
5. **N2와 N4의 성격 차이** — 당뇨·고혈압은 '지금 검사하면 기준에 해당할 가능성'(진단 안 받은 사람 보정), 지방간은 '그 점수의 연구 참가자 비율'(보정 없음). 같은 모양으로 보여 줌.

## 순서

1. **원칙 확정** — 위 1–5. (원칙 2는 기존 규칙 재확인)
2. **입력 바로잡기 (A1 · A2 · B1 · B5)** — 문구 결정이 필요 없는 것. 시험 추가, 390px 확인.
3. **문장 조립 (A3 · A4 · B2)** — 코드는 고치되, 바뀌어 나갈 문장은 시안 표로 먼저 보여 주고 확정 후 반영.
4. **숫자 기준 확인 → 이름 시안 (A6 ① → A5 · A6 ② · B3)** — 기준 표를 먼저 확인받고, 결과·상세·요약 시안을 캔버스에.
5. **기록 · 접근성 (B4 · B6)**.
6. **이번 수정 검수** — 각 항목 '통과' 기준을 실제 화면에서 다시 하고 '검증' 칸을 채움.
