# 1분체크 (1mincheck): 1분이면 보는 내 몸의 확률
### 기획 · 근거자료 · 함수모형 명세 (Claude Code 구현 지시 전 단계)

작성일: 2026-09-30 · 버전 0.3

> **v0.3 변경점**
> - 오늘(2026.9.30) 공개된 **2025 국민건강영양조사 [별첨] 주요결과**의 성·연령별 원표(2016–2025)를 직접 읽었습니다.
> - 고혈압·당뇨·고콜레스테롤·비만·골다공증의 사전확률을 **2023–2025년 3개년 평균**으로 교체했습니다. 단년도 값은 표준오차가 ±2%p 안팎이어서 흔들림이 크기 때문입니다.
> - 고혈압·콜레스테롤 모형을 인구 평균이 정확히 맞는 로지스틱 모형으로 바꿨습니다. 허리둘레 what-if는 연속형(한국인 코호트 HR)으로 바꿨습니다.
> - 당뇨 모형 재보정을 검토했습니다(결론: 절편 유지).
> - 지방간 점수별 유병률을 원본 고해상도 그래프에서 픽셀 단위로 추출했습니다.
> - 위식도역류 what-if 계수, 식생활 문항 검증 프로토콜, v2 후보 근거를 추가했습니다.
> - 모의 인구로 보정 검증을 했습니다(§6-0).

> **v0.2 변경점**
> - 지방간(한국인 비혈액 자가진단 점수), 위식도역류(한국판 GerdQ), 식생활 간이점검 모듈을 추가해서 12개 항목이 됐습니다.
> - OSTA 양성 기준(≤ −1)을 원문으로 확인했습니다.
> - 골다공증 65세 이상 수치를 질병관리청 보도자료 원문으로 확인했습니다.
> - 음주 입력을 4단계로 바꾸고, 운동·폐경 문항을 추가했습니다.

> 이 문서는 코딩 전 단계 산출물입니다. 모든 수치에는 출처를 달았습니다. **[확인]** 표시는 원문 표나 그래프를 직접 열어 확인한 수치이고, **[요약]** 표시는 2차 자료(보도자료·기사)에서 가져온 수치입니다.

## 0. 한 줄 요약

- **입력:** 공통 질문 12개 + 관심 분야별 분기 질문 (최소 경로 합계 22개)
- **출력:** 11개 질환과 식생활 점검, 모두 12개 항목 각각에 대해
  1. "나와 같은 조건의 사람 100명 중 몇 명"
  2. 동년배(같은 나이대·성별) 평균과 비교
  3. 생활습관을 바꾸면 확률이 어떻게 바뀌는지 (what-if)
  4. 근거 논문·통계
  5. 다음에 할 일
- **계산 방식:** 모든 계산은 브라우저 안에서 합니다. 서버에 아무것도 저장하지 않습니다.

## 1. SLEEPS(sleep-math.com) 직접 사용 분석

| 항목 | 관찰 내용 |
|---|---|
| 입력 | 생년월일, 인종, 키, 몸무게, 성별 + ISI 불면 척도 5문항(잠들기·유지·조기각성·만족도·걱정) |
| 출력 | 수면호흡장애 / 무호흡+불면 / 만성불면 확률(%)과 막대그래프 |
| 상세 | 몸무게 ±5kg, 나이 ±5세 변화에 따른 위험도 곡선, "당신 나이 평균보다 높다/낮다" 문구, 질환 설명 |
| 모델 | 삼성서울병원 약 5,000명 수면다원검사 데이터 + XGBoost (JMIR 2023). 서버 API가 11개 점(현재값 ±5 단계)의 확률 배열을 돌려줌 |
| 데이터 | 입력값을 `/predict/upload/`로 서버에 전송·저장함 |

**가져올 점**

- 적은 입력으로 여러 질환을 동시에 판정하는 구조
- what-if 곡선
- 동년배 평균과의 비교

**개선할 점 (우리 앱의 차별점)**

1. **확률 과대추정.** 학습 데이터가 수면클리닉 내원 환자라서, 가상의 46세 남성(BMI 27.8, 불면 경미)도 무호흡 확률이 71.9%로 나왔습니다. 일반인 대상 앱이라면 **기본값(사전확률)을 국민건강영양조사 같은 일반 인구 통계에서** 가져와야 합니다.
2. **체중 민감도 없음.** 80→90kg로 바꿔도 위험도 변화가 "없음"으로 나왔습니다. 우리 앱은 근거가 있는 변수만 what-if에 넣습니다.
3. **느린 응답과 서버 저장.** 결과가 뜨기까지 10초 이상 걸렸고 건강정보를 서버에 저장합니다. 우리 앱은 클라이언트 계산만으로 즉시 결과를 보여줍니다.
4. **무호흡의 핵심 문항 누락.** 코골이, 숨 멈춤 목격, 목둘레를 묻지 않습니다. 우리 앱은 STOP-Bang 문항을 씁니다.

## 2. 핵심 설계 원리: "사전확률 × 개인 보정"

모든 질환을 같은 틀로 계산합니다.

```
① 사전확률 p0 = 같은 나이대·성별 한국인 유병률 (국민건강영양조사 등)
② 개인 보정   = 검증된 간이도구의 점수 → 우도비(LR) 또는 로지스틱 모형 또는 상대위험(RR)
③ 결과 p1     = 보정된 확률  → "100명 중 N명"
④ 비교        = p1 / p0 → 동년배 대비 배수
⑤ what-if     = 바꿀 수 있는 입력(체중·허리·흡연·음주)을 바꿔 p1 재계산
```

도구마다 근거 수준이 달라서 **출력 유형을 4가지로 구분**합니다. 화면에도 이 유형을 표시합니다.

| 유형 | 의미 | 해당 질환 |
|---|---|---|
| **A. 모형 확률** | 한국인 데이터로 만든 모형이 직접 확률을 계산 (A′: 점수별 실측 유병률 표) | 당뇨(숨은 당뇨), 지방간(A′) |
| **B. 보정 확률** | 사전확률에 우도비나 상대위험을 곱한 추정 | 고혈압, 고콜레스테롤, 골다공증, 우울 |
| **C. 점수 등급** | 검증된 점수와 등급만 제시하고, 확률은 동년배 유병률만 참고로 표시 | 수면무호흡, 불면, 불안, 비만, 위식도역류 |
| **D. 참고 지표** | 검증되지 않은 자체 점검표. 개선 포인트만 제시 | 식생활 |

- **허리둘레·BMI 연속 효과 [확인]:** 한국인유전체역학조사(KoGES, 40–69세 4,454명, 4년 추적)에서 고혈압 발생 위험비(1 SD당, 나이·흡연·음주·당뇨·가족력 보정)는 다음과 같습니다.
  - 허리둘레: 남 1.50 (95% CI 1.36–1.67, SD 7.33cm), 여 1.44 (1.30–1.60, SD 9.12cm)
  - BMI: 남 1.39 (1.25–1.54, SD 2.86), 여 1.31 (1.19–1.44, SD 3.09)
  - 1cm·1단위로 환산하면 허리 1cm당 남 ×1.057, 여 ×1.041이고, BMI 1당 남 ×1.122, 여 ×1.091입니다.
  - 허리둘레가 BMI보다 예측력이 좋았습니다 (AUROC 남 0.62 vs 0.58, 여 0.66 vs 0.57).

## 6. 함수 모형 (구현 명세)

### 6-0. 보정 검증 (모의 인구 검사) — v0.3 수행 결과

실제 사용자 데이터 없이 할 수 있는 검증을 Python으로 먼저 돌렸습니다. Claude Code는 같은 검사를 단위 테스트로 옮기면 됩니다.

| 검사 | 방법 | 결과 |
|---|---|---|
| 고혈압·콜레스테롤 평균 재현 | 12개 칸에서 `f·p(비만) + (1−f)·p(비비만)` = p0인지 확인 | ✅ 모두 오차 <0.0001%p |
| 확률 범위 | 모든 칸, 모든 입력 조합에서 0 < p < 1 | ✅ (v0.2 RR 방식은 여 70+ 비만에서 98% → 실패, 그래서 교체) |
| 당뇨 점수 구간 대조 | 테스트 벡터의 모형 확률 vs 논문의 점수 구간별 실측 비율(2/6/12/19%) | ✅ 같은 구간 안 또는 근처 |
| 지방간 점수표 | 점수 증가에 따라 확률이 단조 증가하는지 | ✅ |
| 우울·골다공증 베이즈 | LR+ > 1 > LR−이고, 사후확률이 사전확률을 사이에 두는지 | ✅ |

**Claude Code에 추가할 검사:** 합성 인구 1만 명(연령·성별은 추계인구 비율, 비만은 §3-8 비율로 추출)에 대해 고혈압 모형 평균 ≈ 전체 유병률(±0.5%p)인지 확인합니다.

공통 유틸:

```
band(age): 19–29→0, 30–39→1, 40–49→2, 50–59→3, 60–69→4, 70+→5
expit(z) = 1/(1+e^(−z)),  logit(p) = ln(p/(1−p))
bmi = weight / (height/100)^2
obese = bmi >= 25                 # 대한비만학회 기준 (23–24.9 비만 전단계)
bayes(p, LR) = (p/(1-p)·LR) / (1 + p/(1-p)·LR)
ratio = p1 / p0 → 라벨: <0.8 "낮음" · 0.8–1.25 "비슷" · 1.25–2 "높음" · ≥2 "매우 높음"
```

### 6-1. 당뇨: 숨은(진단 안 된) 당뇨 확률 [유형 A]

- **htn 입력** = `dx.HTN || bp == high`

- **동년배 비교값**은 3-3의 당뇨 유병률(진단된 사람 포함)과 전단계 유병률을 함께 보여줍니다. 모형 출력은 "진단 안 된 당뇨"이므로 두 값의 의미가 다르다는 것을 문구로 구분합니다.

**재보정 검토 결과 (v0.3): 절편 −5.608을 그대로 둡니다.**

- 개발 당시 진단 안 된 당뇨 비율은 341/9,602 = **3.55%**였습니다.
- 현재 값은 `유병률 × (1−인지율) ÷ (1−유병률×인지율)`로 추정했습니다.
  - 19세 이상, 2025년 유병률 10.3%, 인지율 74.7%로 계산하면 **2.82%**입니다.

- 대신 화면에 "±약 25% 상대 오차"라는 불확실성 문구를 둡니다.

**외부 대조값 [확인]:** 원 논문이 보고한 점수 구간별 실제 숨은 당뇨 비율은 ≤4점 2%, 5–7점 6%, 8–9점 12%, ≥10점 19%입니다. 모형 출력이 이 범위와 크게 어긋나지 않는지 단위 테스트에서 확인합니다. 아래 테스트 벡터의 8점 사례(9.4%, 10.9%)는 12% 근처입니다.

### 6-2. 고혈압 [유형 B]

**v0.3에서 모형을 바꿨습니다.** v0.2의 "유병 비율(RR) 곱하기" 방식은 고령 여성처럼 유병률이 높은 칸에서 100%를 넘는 문제가 있었습니다. 70세 이상 여성 비만자는 98%가 나와 95%로 잘라야 했고, 그러면 인구 평균도 틀어졌습니다. 그래서 **오즈비(OR)를 쓰는 로지스틱 형태로 바꾸고, 연령·성별 칸마다 절편을 수치 계산으로 맞춥니다.**

```
# ① 상수: 비만 오즈비 (전체 성인에서 유병 비율 1.9가 되도록 환산)
#    전체 고혈압 23.2%, 비만율 39.5%(2025), PR 1.9  →  OR_htn = 2.33
#    (고콜레스테롤: 전체 24.5%, PR 1.45             →  OR_chol = 1.64)
# ② 칸별 절편 a[sex][band]: 다음 식을 이분법으로 풀어서 미리 계산해 JSON에 저장
#    f·expit(a + ln OR) + (1−f)·expit(a) = p0
#    p0 = §3-1 3년 평균, f = §3-8 연령·성별 비만율 3년 평균
# ③ 개인 확률
if dx.HTN: "관리 중" 카드 (가정혈압 관리 안내)
elif bp == high: "고혈압 기준 해당 (재측정·진료 권장)", 확률 표시 안 함
else:
  p1 = expit(a[sex][band] + (obese ? ln OR_htn : 0))
  bp == elevated → 확률은 그대로 두고 "주의 혈압" 배지 표시 (정량 근거 미확보)
# ④ what-if: 연속형 (계단 없이 부드럽게 변함)
  허리를 알면:  logit(p_new) = logit(p1) + β_wc[sex]  × Δ허리(cm)   β_wc  = 0.0553(남), 0.0400(여)
  모르면:       logit(p_new) = logit(p1) + β_bmi[sex] × ΔBMI         β_bmi = 0.1151(남), 0.0874(여)
  (KoGES 발생 위험비를 SD로 나눠 환산. HR을 유병 오즈에 적용하는 근사이므로 "추정"으로 표시)
  what-if에서는 obese 플래그를 다시 판정하지 않습니다(연속 효과와의 이중 계산 방지).
```

- **보정 검증:** 12개 칸(성 2 × 연령 6) 모두 비만자와 비비만자의 가중평균이 p0와 오차 0.0001%p 이내로 일치합니다(§6-0).
- **테스트** (3년 평균 기준, Python으로 검산함)

| 입력 | 결과 | 비교 |
|---|---|---|
| 46세 남, BMI 27.8 | **34.9%** | 비비만이면 18.7%, 동년배 27.6% |
| 위 사람이 허리 −7cm (what-if) | **26.7%** | |
| 위 사람이 허리를 모르고 체중 −7kg (ΔBMI −2.29) | **29.2%** | |
| 58세 여, 비비만 | 22.7% | 비만이면 40.7% |
| 75세 여, 비만 | 80.0% | v0.2 방식에서는 상한에 걸리던 칸 |

### 6-5. 수면무호흡: STOP-Bang [유형 C]

S 코골이 · T 피로 · O 숨멈춤 목격 · P 고혈압(`dx.HTN` 또는 `bp==high`) · B BMI>35 · A 나이>50 · N 목둘레>40cm · G 남성

```
score = 합계 (0–8)
0–2 → 저위험, 5–8 → 고위험
3–4 → 고위험 if (S+T+O+P ≥ 2) and (남성 or BMI>35 or 목>40), 아니면 중위험
```

- **참고치:** 40–69세이면 동년배의 수면호흡장애(AHI≥5) 유병률 남 27%, 여 16%를 함께 보여줍니다.
- **확률로 바꾸지 않는 이유:** 한국 수면클리닉 연구에서 STOP-Bang(≥3)은 민감도 97%, 특이도 19%였습니다. "낮으면 안심"에는 강하지만 "높다고 확정"하기에는 약한 도구입니다. 이 점을 문구에 반영합니다.
- 한국인 BMI 분포에서는 B(>35) 항목이 거의 해당되지 않습니다. 한국 일반인 수정판(BMI>25, 허리>85, 당뇨 포함; Korea Univ. 연구)을 v2 후보로 둡니다.
- **what-if:** 체중(BMI)과 고혈압 변화만 반영합니다.

### 6-9. 골다공증: OSTA [유형 B]

```
OSTA = trunc((체중kg − 나이) × 0.2)
위험: > −1 낮음 · −4 ~ −1 중간 · < −4 높음
여성 50+: p0 = OST[F][band 50s/60s/70+]
  OSTA ≤ −1 (양성) → LR+ = 0.879/0.315 = 2.79
  OSTA > −1 (음성) → LR− = 0.121/0.685 = 0.177
  (한국 폐경 전후 여성 1,488명: 골다공증 민감도 87.9%, 특이도 68.5%)
남성 50+: 동년배 유병률만 표시 (OSTA 남성 검증은 v2)
```

- **양성 기준 확인 완료 [확인]:** 대한산부인과학회지 2003(중앙대 폐경클리닉 1,488명)은 민감도와 특이도를 "**중간+고위험군을 합친 기준**", 즉 OSTA ≤ −1로 보고했습니다.
- **다른 한국 연구도 같은 결과입니다.** 폐경 후 1,101명을 대상으로 한 연구에서 T ≤ −2.5 기준 민감도 87%, 특이도 67%가 나왔습니다. 위험군별 실제 골다공증 비율은 저위험(>−1) **2%**, 고위험(<−4) **64%**였습니다. 이 값은 클리닉 표본이라 일반 인구보다 높을 수 있어서, 카드의 "계산 방법 보기"에 참고치로만 둡니다.
- **또 다른 한국 연구(1,559명, 2002–04)** 에서는 OSTA가 비교한 6개 지표 중 AUC 0.920으로 가장 우수했습니다.
- **테스트** (v0.3, 2년 평균 사전확률 기준)

| 58세 여 55kg | 0 | 13.5% → **2.7%** |

### 6-11. 위식도역류: 한국판 GerdQ [유형 C + 사후확률 참고]
근거: *Validation of the Korean Version of the GerdQ* (2019, PMC6326199, GERD 의심 환자 149명, 내시경·pH검사·PPI 반응을 기준으로 삼음) [확인]

```
gerdGate == 0 → "역류 증상 없음"
score = gq1+gq2+gq3+gq4+gq5+gq6  (0–18; 증상이 전혀 없어도 역채점 때문에 6점)
score ≥ 8 → "위식도역류질환 가능성 높음"  (민감도 64.9%, 특이도 71.4%, PPV 88.1%, NPV 38.5%)
score 3–7 (원판 기준) → 가능성 낮음. 단, NPV가 낮아서 "증상이 계속되면 진료"로 안내
```

- 확률로 바꾸지 않습니다. 검증 표본이 이미 증상이 있는 환자였고, 인구 사전확률(4~7%)과 모집단이 다르기 때문입니다.
- 동년배 참고로 "한국 성인 약 4~7%가 주 1회 이상 증상"과 연령 증가 경향을 보여줍니다.
- **what-if (v0.3, 상대 변화만 표시):** 한국인 미란성 식도염 다변량 OR(§3-10)을 씁니다.

  ```
  factor = Π OR_k^(현재_k − 변경후_k)
     OR: BMI≥25 → 1.42, 현재 흡연 → 1.54, 음주 → 1.34
  표시: "금연하면 역류성 식도염 위험이 약 1/1.54 ≈ 35% 줄어드는 것과 관련돼요"
     예: 비만·흡연·음주를 모두 개선하면 1/(1.42×1.54×1.34) = 1/2.93 → 약 66% 감소
  ```

  - 절대 확률로 바꾸지 않습니다. 증상 점수(GerdQ)와 내시경 소견은 서로 다른 결과이기 때문에, "관련 위험의 상대적 변화"라고만 표현합니다.
  - 야식, 식후 바로 눕기, 취침 시 머리 올리기는 가이드라인상 권고사항이지만 한국인 정량 수치가 없으므로 문구로만 안내합니다.

### 6-12. 식생활 간이 점검 [유형 D: 참고 지표, 비검증]

```
diet = round((d1+…+d7) / 14 × 100)     # 0–100
등급(자체): ≥75 양호 · 50–74 보통 · <50 개선 필요     ← 검증된 절단점이 아님. 화면에 명시
개선 포인트 = 0점인 문항을 KHEI 요소명과 함께 우선순위로 나열
동년배 비교(맥락용): KHEI 평균(20대 50.3 … 70+ 66.1), 아침 결식률(19–29세 59.2% 등), 나트륨 평균 3,075mg vs 목표 2,300mg
```

- **주의:** 이 점수는 KHEI와 **같은 척도가 아닙니다.** KHEI는 24시간 회상 섭취량으로 계산합니다. 따라서 "KHEI 평균과 직접 비교"하지 않고, "한국인은 평균적으로 이 항목이 약해요" 같은 맥락 정보로만 씁니다.
- **다른 모듈과 연결 (문구만):** d6(짠 음식) → 고혈압 카드, d7(단 음료) → 당뇨·지방간 카드, d1(아침 결식) → 비만 카드에 "관련 습관" 칩으로 표시합니다. 확률 계산에는 넣지 않습니다(정량 근거 미확보).
- **검증 프로토콜 (v0.3에서 설계; 실행하려면 원시자료 이용 신청이 필요):** 국민건강영양조사 원시자료는 누리집에서 이용자 등록과 서약을 한 뒤 내려받을 수 있습니다. 이 세션에서는 신청할 수 없어서 절차만 명세합니다.
  1. **데이터:** 2022–2024 원시자료 중 19세 이상. 사용 변수는 식생활 설문(아침식사 빈도, 외식), 식품섭취빈도, 24시간 회상 기반 KHEI 점수, 나트륨·당 섭취량입니다.
  2. **대응 변수 만들기:** d1은 아침식사 주당 빈도로 만듭니다. d2~d5와 d7은 24시간 회상의 해당 식품군 섭취 여부나 식품섭취빈도 문항으로 근사합니다. d6은 나트륨 섭취량의 3분위(역순)로 대체합니다.
  3. **분석:** 7문항 점수와 KHEI 총점의 스피어만 상관계수를 구하고, 가중치를 적용한 최적 조합을 찾습니다. 목표는 ρ ≥ 0.4입니다. KHEI 하위 25%를 식별하는 AUC도 구합니다(목표 ≥ 0.70). 연령·성별 하위집단에서도 따로 봅니다.
  4. **절단점:** 사용 중인 75/50 대신, KHEI 하위 25%를 식별하는 Youden 최적점으로 등급 경계를 바꿉니다.
  5. **판정:** 목표를 달성하면 유형 D를 "검증된 간이 지표(유형 C)"로 올리고, 실패하면 NQ-A 라이선스를 검토합니다.
- 결과가 나오기 전까지는 v0.2의 "참고 지표" 표시를 유지합니다.

### 6-15. 실측 보정 v1 · 또래 백분위 (2026-10-01, `engine/src/calibrate.ts`, `engine/src/percentile.ts`)

국민건강영양조사 제9기(2022–2024) 원시자료 성인 16,492명으로 엔진을 검증했다(`analysis/`). 진단받지 않은 사람만, 가중치 wt_itvex/3, 혈압은 '모름', 실측 정의는 이용지침서 표 20.
- **문제:** 고혈압·콜레스테롤은 '진단받은 사람까지 포함한 유병률'에서 출발해 진단받지 않은 사람에게 보여주므로 크게 나왔다(전체 평균 고혈압 23% vs 실측 8.8%, 콜레스테롤 24.9% vs 10.5%). 진단받은 사람 대부분이 약으로 수치가 내려가 빠지기 때문.
- **보정:** 로지스틱 재보정 logit(p′) = a[성별·연령대 6구간] + b·logit(엔진 확률), 당뇨·고혈압·콜레스테롤·골다공증. 엔진 식은 그대로, 화면(`web/src/lib/view.ts`)에서 적용. 바꿔보기·상세·기록·백분위 모두 같은 보정값.
- **확인 (보정을 만든 자료와 다른 자료):** 2022–2023으로 만들고 2024로 확인(골다공증은 2024 짝/홀 행). 확인 자료 평균: 당뇨 보정 3.2% / 실측 3.9%, 고혈압 8.5 / 9.9, 콜레스테롤 10.0 / 11.5, 골다공증 13.0 / 13.6. AUC 당뇨 0.758→0.754, 고혈압 0.710→0.725, 콜레스테롤 0.601→0.646, 골다공증 0.747→0.776. 최종 계수는 전체 자료로 다시 만들었다. 결과: `analysis/results/calibration.json`, `validation.json`.
- **또래 평균:** 같은 성별·연령대에서 '진단받지 않은 사람'의 실측 비율(가중). 당뇨의 인지율 환산식(spec §6-1)은 이 실측 비율로 대체했다.
- **또래 중 내 위치:** 같은 성별·나이 ±5세, 진단받지 않은 사람의 보정 확률 분위수(5–95%). 칸 최소 119명. 상세 화면에 "100명 중 낮은 쪽에서 약 N번째".
- **한계:** 고콜레스테롤은 보정 후에도 AUC 0.65로 구분력이 약하다 → 혈액검사·검진 수치 입력을 우선 안내. 실측 정의상 골다공증은 50세 이상 남성·폐경 후 여성 기준.
- **개발자 모드:** 주소에 `?dev=1616`이 있을 때만(기기에 기억하지 않음) 엔진값→보정값, 보정 그룹·계수를 함께 보여주고, `/dev`에 확인 표, 예시 불러오기 버튼을 연다. 일반 주소는 보정값만.
- **원시자료 취급:** 개인 단위 자료(`docs/sas`, `analysis/.cache`)는 git 제외. 저장소에는 집계(계수·비율·분위수)만. 출처 표기: 국민건강영양조사 제9기(2022–2024) 원시자료, 질병관리청.

**검증 후 개선 (2026-10-01, 시나리오 검증 반영)**
- 공복혈당 126 미만 입력 시 '현재 당뇨 가능성'은 규제 회귀(앱 당뇨 확률 + 연속 공복혈당, `engine/src/glucose_model.json`, 2022–2024 학습)로 다시 추정. "현재 당뇨 가능성 추정 약 ○%"(소수 한 자리, 0.1% 미만은 "추정 0.1% 미만"). 100–125는 공복혈당장애 + 당화혈색소 추가 확인. 126 이상은 확률 없이 "당뇨 기준에 해당하는 수치, 확인 필요". 분리 평가(2022–23 학습/2024 평가, 126 미만): AUC 0.936(조사 설계 부트스트랩 95% 0.916–0.955), Brier 0.0085 — 이 성적은 분리 평가 모형의 것.
- 혈압 숫자 140/90 미만이면 고혈압 확률 대신 측정 상태(정상·주의혈압·고혈압 전단계).
- 콩팥: eGFR 없이 요단백 1+ 이상이어도 재검 안내, 단일 검사로 만성콩팥병이라 하지 않음.
- 확률 카드마다 또래 비교와 별도의 공식 검진 권고 줄. 치매 위험요인의 LDL 표현은 "고지혈증 진단 이력".
- 분석 추출(`analysis/extract.py`)은 이용지침서 코드 기준(가족력 모름·진단 모름 제외, 복약 유효 코드)으로 수정, 개인 자료는 파일로 남기지 않음. 같은 조건 비교에서 보정 성능 차이가 없어 보정 v1 유지.

**검진 수치 선택 입력 (2026-10-01, `web/src/lib/labs.ts`)** — 비워도 되고, 넣으면 추정보다 실제 수치가 먼저 나온다. 항목 정의는 `LABS` 목록 하나라 한 줄을 지우면 화면·저장·계산에서 함께 빠진다.
- 생활 화면(접힌 칸): 혈압 수축기/이완기 → 혈압 범주를 숫자로 자동 결정(120/80 미만 정상, 120–139/80–89 주의, 140/90 이상 높음). 공복혈당.
- '검진 수치 넣기' 화면(`/checkup`, 생활 화면 링크와 결과 화면 카드에서): 총콜레스테롤·중성지방·HDL, eGFR, 요단백(음성/±/1+/2+ 이상).
- 반영: 공복혈당 126↑ → 당뇨 기준(먼저 확인할 것), 100–125 → 전단계 안내, 100 미만 → "실제 가능성은 이보다 낮아요". 총콜레스테롤 240↑ → 기준 이상, 미만 → 검진 수치 표시(추정 % 대신). 대사증후군은 넣은 수치만큼 확정. 콩팥은 eGFR 60 미만 또는 요단백 1+ 이상이면 "확인 필요"(KDIGO 2024), 둘 다 정상이면 "검사 수치 정상", 요단백은 선별 점수 1점에도 반영. 10년 당뇨 카드는 공복혈당 126↑이면 숨긴다.
- 값은 `Input.lab`으로 기록에 함께 저장. 엔진은 쓰지 않는다.

- 체중(−20~+10kg), 허리(−15~+10cm), 흡연 토글, 음주 4단계, 운동 토글
- 영향받는 카드: 당뇨, 고혈압, 콜레스테롤, 비만, 지방간, STOP-Bang
- "지금 → 바꾼 후" 값과 차이를 즉시 보여줍니다.
  - 예: 숨은 당뇨 9.4% → 2.9% (−6.5%p)
  - 예: 지방간 약 72% → 약 29%
- 여러 카드의 변화를 한 줄로 요약합니다. 예: "허리 7cm를 줄이고 운동을 시작하면 → 3개 항목 개선"

**동년배 곡선 (SLEEPS식):** 나이 ±10세 범위에서 동년배 유병률 계단 곡선 위에 내 추정점을 찍습니다.

## 9. 규제 · 라이선스 · 개인정보 (상업화 전 필수 점검)

목표: 이 문서(1분체크_기획_근거_함수모형.md)의 §5 입력, §6 함수, §7 화면을 구현한 모바일 우선 단일 페이지 웹앱.
