# 1분체크 디자인 기준 (2026-10-08 개정)

**구성은 Jeton, 색은 1분체크 초록.** Jeton(`DESIGNstyle-jeton.md`, jeton.com)의 편집 디자인 구성 — 흰 바탕, 넓은 여백, 크고 촘촘한 제목, 둥근 카드, 아래에서 받쳐 올리는 옅은 그림자, 떠 있는 메뉴 알약 — 을 따르고,
브랜드색은 건강 서비스에 맞게 원래 1분체크의 **진초록 #163300 + 라임 #9fe870**을 쓴다. 글꼴은 **프리텐다드**, 자간 **-0.5%(-0.005em)** 전체 통일.
코드: 토큰 `web/src/index.css`(Tailwind v4 `@theme`), 부품 `web/src/components/ui/`(shadcn), 아이콘 **lucide-react만**. 이모지·글자 기호 아이콘 금지.

## 글자 (프리텐다드, 자간 -0.005em 전체)
| 역할 | 크기 / 줄간격 | 굵기 |
|---|---|---|
| display (랜딩 첫 제목) | 64–140px / 0.92 | 500 |
| heading-lg | 56px / 1.0 | 500 |
| heading (또래 'N번째로 위험', 큰 숫자) | 33px / 1.1 | 500 |
| heading-sm (화면·판정 제목) | 28px / 1.15 | 500 |
| subheading | 23px / 1.2 | 500 |
| body / body-sm / caption | 16 / 14 / 12px | 400 |
굵기는 400·450·500만. 위계는 크기와 색으로.

## 모양
- 카드·입력 16px, 버튼 12px, 알약 9999px. 그림자: 카드 `0 -4px 16px rgba(0,0,0,.05)`, 떠 있는 것 `0 8px 24px rgba(22,51,0,.12)`.
- 최대 폭 1280px(랜딩)·440px(앱 화면). 섹션 사이 96–144px(모바일 72–96px).

## 결과 표현 규칙
- 또래: 작은 글씨 "100명 중" + 큰 글씨 **"N번째로 위험"**(위쪽 절반, 위험한 쪽부터) / **"N번째로 좋음"**(아래쪽 절반). 내 점은 항상 맨 위(z-index).
- 이대로면 vs 바꾸면: 막대 = 손잡이(몸무게는 kg 크게·BMI 작게, 표준 몸무게 구간 괄호 / 허리는 기준선). 아래 진초록 판 "만약 [허리 −3cm] 줄이면?"에 이전 값(줄 긋기) → 새 값(세어지며, 좋아지면 라임·나빠지면 분홍빨강).
- 결과 화면 맨 아래 문구는 "논문과 국가 통계를 바탕으로 한 예측". '진단이 아니에요'는 자주 묻는 질문·랜딩 바닥글·진료용 요약에.

## 랜딩 구성 (jeton.com 순서)
1 꽉 찬 첫 화면(입체 원반 더미 + 왼쪽 아래 큰 제목 + 오른쪽 아래 버튼, 아래 가운데 떠 있는 메뉴 알약·오른쪽 아래 '자주 묻는 질문') → 2 가운데 큰 문장 + 떠다니는 결과 조각 → 3 큰 낱말 셋(또래 중 나·줄이면?·검진 풀이) → 4 진초록 띠(미니 체험 + 01–05 단계) → 5 휴대폰 화면 → 6 가운데 질문 문장 + 줄이면 예시 → 7 검진 풀이 → 8 100명 점 + 떠다니는 원 → 9 소개 영상 → 10 자주 묻는 질문 → 11 마지막 큰 문장 · 큰 글자 바닥글.
후기(가짜 후기)는 넣지 않는다.
