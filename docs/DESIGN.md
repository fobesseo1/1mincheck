# 1분체크 디자인 기준 (2026-10-15 개정)

**기준 화면은 새 결과 화면**(`web/src/components/result-v4.tsx`, Claude 디자인 캔버스 '1분체크 결과 화면')이다. 첫 화면을 포함한 모든 화면이 이 화면과 같은 바탕·글자 단계·여백·부품을 쓴다.
예전 기준(Jeton 구성 + 진초록·라임 + 연두 그라데이션 바탕 + 유리 질감)은 쓰지 않는다. 예전 파일·자료는 지우지 않고 남겨 둔다.

코드: 토큰 `web/src/index.css`(Tailwind v4 `@theme`), 부품 `web/src/components/ui/`(shadcn), 아이콘 **lucide-react만**. 글꼴 **프리텐다드**, 자간 **−2%(−0.02em, 2026-10-16 확정)** 전체.

## 0. 만드는 도구 (반드시)
- **shadcn/ui**(`components.json`: style new-york, Radix 기반)로 부품을 만든다. 새 부품이 필요하면 shadcn 방식으로 `components/ui/`에 추가하고, 화면에서 날 HTML로 같은 모양을 다시 짜지 않는다.
- **Tailwind CSS v4** 유틸리티 + `index.css`의 `@theme` 토큰만 쓴다. 색·크기를 화면마다 16진수로 새로 적지 않는다(새 값이 필요하면 토큰을 먼저 추가).
- **lucide-react** 아이콘만 쓴다(선 2px). 직접 그린 SVG는 소주병처럼 아이콘에 없는 그림일 때만.

## 1. 원칙 (사용자 먼저)
1. **쉬운 말이 먼저, 숫자는 그다음.** %·배수·점수는 화면 앞에 내세우지 않는다. "100명 중 21명", "40대 남성 중 3번째로 위험"처럼 말한다.
2. **한 덩어리에 한 가지 이야기.** 줄 하나 = 이름 + 한 문장 + 그림 하나. 나머지는 **자세히**를 눌러야 보인다.
3. **같은 말을 두 번 하지 않는다.** 제목·설명·할 일이 같은 내용을 반복하면 하나로 합친다.
4. **위계는 크기·굵기·색 세 가지로만.** 한 줄에서 크고 색이 있는 것은 핵심 하나(숫자 + 위험/안전)뿐이다.
5. **눌러서 바꾸는 곳은 바로 알 수 있게.** "게이지 바를 움직여 보세요" + 깜빡이는 화살표, 한 번 움직이면 안내는 사라진다.
6. **같은 일은 같은 모양.** 허리·몸무게·술처럼 바꾸는 것이 달라도 같은 틀(그림 → 이름·숫자 → 게이지 바)을 쓴다.

## 4. 글자 (프리텐다드, 자간 −2%(−0.02em), 굵기 400·500·600만)
| 크기 | 굵기 | 쓰임 |

| 30px + 15px | 600 + 400 | 바꾸는 값: 숫자는 크게, 단위는 작게 회색 (예: **40** 인치) |

- 숫자와 단위는 항상 다른 크기다(숫자 크게, 단위 작게 회색). 숫자는 `tabular-nums`.
- **숫자와 단위는 붙인다**(330g · 1점 · 3개 · 3번째로). 같은 덩어리로 묶어 줄이 바뀌어도 떨어지지 않게 한다. 숫자 옆 설명은 뒤에 따로 「/ 간에 부담되는 양」처럼 쓰고, 「·」로 줄을 시작하지 않는다.
- 회색 제목 + 검은 제목처럼 한 제목을 두 색으로 나누지 않는다.

## 7. 그림
- 아이콘은 lucide-react만, 선 2px. 이모지·글자 기호(‹ ⌄ ★ 등) 금지.
- **체형 캐릭터**: 84×126 칸, 몸무게 = 체형 단계(가장 가까운 그림), 허리 = 배(기준 이상이면 배 나온 그림). 그림 뒤에 색·빛 없음. 그림: `web/public/characters/`.
- **소주병**: 체형 그림과 같은 84×126 칸. 실제 소주병 비율(넓은 몸통 · 꺾인 어깨 · 위로 곧게 좁아지는 긴 목 · 줄무늬 뚜껑), 잉크 선 2px, 마신 양만큼 아래부터 잉크로 찬다.
- 그림이 들어가는 칸은 같은 크기·같은 자리. 종류가 달라도 배치가 따로 놀지 않는다.

## 8. 숫자·문구 규칙
- 가능성: "지금 ○○하면 ○○으로 나올 사람이 이런 조건에서 100명 중 N명쯤이에요. 같은 또래는 평균 M명이에요." (1 미만은 "1명도 안 돼요")
- 또래 순위: "○○대 남성 중 **N**번째로 **위험/안전** (100명 중)". 51번째부터는 위험 쪽에서 센다(딱 50은 위험 쪽).
- 단계 말: 낮은 편 · 또래와 비슷 · 조금 높은 편 · 높은 편 · 매우 높음. 빨강은 높은 편부터.
- 바꿨을 때: "허리 36인치인 사람들은 혈압이 높은 사람이 100명 중 **58**명이에요" + "지금보다 6명 적어요". 원인처럼 단정하지 않는다.
- 판정 문구 안의 %는 화면에 낼 때 '100명 중 N명'으로 바꾼다(`plain()`).
- **항목 상세 화면만 예외 (2026-10-15)**: 맨 위만 '40대 남성 중 3번째로 위험 (100명 중)'. 그 아래는 모두 %로 쓴다 — '또래보다 고혈압 가능성이 높아요' → '나의 예상 가능성 21% / 40대 남성 평균 14%' → '몸무게와 허리가 줄어든다면?'(몸무게 92kg → 70kg / 고혈압 가능성 21% → 9%, 하나씩 따로 바꾼 결과) → '나이대별 고혈압 가능성'(막대 %, 나의 예상 가능성 점선). 상세 화면 아래쪽에 '100명 중 ○명'을 섞지 않는다.
- '응급'·'119'·'응급실'은 절대 쓰지 않는다. 급할 때는 "지금 바로 병원 가세요"만.
- 맨 아래 한 줄: "논문과 국가 통계를 바탕으로 한 예측이에요".
- **줄바꿈**: 한글은 단어 중간에서 끊지 않는다(`word-break: keep-all`). 두 문장 이상이면 문장이 끝나는 곳에서 줄을 바꾼다. 목록(「· 」로 이은 것)은 항목 사이에서만 넘긴다.
- **줄 이름은 한 줄**: 대사증후군 · 검진·접종 · 허리÷키 · 치매 위험. 가운뎃점·나눗셈 기호 앞뒤에 띄어쓰기를 하지 않는다. 안 들어가면 말을 줄인다(고콜레스테롤 → 콜레스테롤, 간·술 양 → 주량).
- 시안·화면을 내놓기 전에 390px에서 실제로 띄워 자동 줄넘김과 숫자-단위 틈을 확인한다.

- 큰 제목 유틸리티 `kr-display`·`kr-h1`·`kr-word`·`kr-h2`·`kr-h3`·`kr-lead`·`kr-body` 는 랜딩에서만.
