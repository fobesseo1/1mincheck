# 결과 화면 전면 개편 계획 (2026-10-15)

상태: **계획 단계. 코드는 아직 손대지 않음.**
원칙: **한 사람에 맞추지 않는다.** 누구의 어떤 정보를 넣어도 같은 틀로 한눈에 읽히는 결과를 만든다. 예시 인물·숫자는 점검용일 뿐 설계 기준이 아니다.

## 1. 목표

- **사용자:** 40–50대 남녀. 건강에 관심은 있지만 병원 갈 시간·여유가 없다. 나뿐 아니라 배우자·애인·부모·형제·친구를 챙긴다.
- **입력:** 누구나 아는 숫자 4개(나이·키·몸무게·허리) + 간단한 생활습관(담배·술·운동) + 가족력·진단 여부. 혈압·검진 수치는 알면 넣는다.
- **결과에서 바로 알아야 할 것:**
  1. 당뇨·고혈압·지방간이 지금 어떤 상태인지, 또래보다 위험한지 — **탭 없이 한 번에**
  2. 왜 그런지 — 점수표 내용을 짧게
  3. 뭘 하면 되는지 — 아주 짧게 한 줄
  4. 몸무게·허리·술 등을 바꾸면 근거 있는 숫자로 무엇이 달라지는지 — 흥미 있게
  5. 결과를 카톡으로 보여주며 "이것 좀 봐요" 하고 이야기를 꺼내고 병원에 가게 하기
- 나머지 자세한 내용은 누르는 사람만 본다.

## 2. 지금 화면의 문제 (여러 경우로 돌려 확인)

| 문제 | 어떤 경우에 생기나 |
|---|---|
| 맨 위가 와닿지 않음 | 판정 한 줄만 크게 나오고, 정작 또래 대비 많이 높은 항목은 아래 탭 안에 숨는 경우가 많다 |
| 탭을 바꿔야 보임 | 세 질환을 한 번에 비교 못 한다. 첫 탭이 '진단받아 관리 중'·'검사로 확인' 같은 상태면 정보 없는 화면부터 보인다 |
| 상태마다 모양이 제각각 | 가능성 숫자 / 진단 관리 중 / 검진 수치 기준 이상 / 술 때문에 계산 제외 / 허리 몰라 범위 / 나이가 계산 대상 밖 — 각각 다른 모양·문구로 나와 한눈에 비교가 안 된다 |
| 순위 문구가 오해를 부름 | 가운데 순위(33번째·46번째)도 "높아요"·빨강으로 나온다. 반대로 점수식 항목(지방간)은 또래 2배인데 중간 순위로 나오기도 한다 |
| 이유가 숨어 있음 | "나이 +3, 허리 +2…" 점수표가 상세 화면에만 있다 |
| 바꿔보기가 시시함 | 미래 위험 계산이 나이 40–69세·진단 없음·허리 입력·검진 혈압 같은 조건을 다 맞춰야 나온다. 조건이 하나만 빠져도 비만도 이름만 바뀐다. 맞춰도 기준선(허리 90·85cm, BMI 25·30)에서만 계단처럼 바뀐다. 몸무게는 10년 당뇨 계산에 아예 없다 |
| 지금 가능성도 계단식 | 엔진의 고혈압 가능성은 BMI 25를 넘나들 때 크게 뛰고, 그 사이에서는 거의 그대로다 |
| 술·담배·운동은 바꿔볼 수 없음 | 입력만 받고 결과에서 움직여 볼 수 없다 |
| 가족용 흐름이 없음 | 모든 문구가 '나' 기준이다 |
| 공유가 약함 | 앱 소개 문구와 주소만 보낸다 |

## 3. 레퍼런스에서 가져올 것

| 사례 | 가져올 것 | 가져오지 않을 것 |
|---|---|---|
| NHS Heart Age·호주 Heart Foundation | 쉬운 결론 하나 + 바로 아래 "바꿀 수 있는 것". 공유로 퍼짐 | 검증 안 된 '건강나이' 숫자 |
| ADA·Diabetes UK 위험 점수 | 결과 바로 아래 항목별 점수, 진료에 가져갈 요약 | 외국 계수 그대로 쓰기 |
| 건보공단 건강모아·체크업+ | 국내 사용자에게 익숙한 '검진 → 예측' 틀. 둘 다 검진·로그인이 필요 → **우리 차별점: 검진표 없이 1분, 가족 것도 대신** | 로그인·인증 |
| Oura | 대표 결론 + 기여 요인 칩(+/−) | 근거 없는 종합 점수 |
| 공유 카드형 서비스 | 개인 숫자를 최소로 담은 요약 카드 + 한 줄 | 결과 숫자를 동의 없이 링크로 퍼뜨리기 |

## 4. 바꿔보기 근거 (두 겹, 구분해서 표시)

### 4-1. 나 같은 한국인 데이터 (새 분석, 국민건강영양조사 2022–2024 원시자료 — 이미 확보)
- 같은 성별·나이대에서 허리·BMI·술 양·흡연·운동에 따라 **실제로 잰 값이 기준을 넘은 사람 비율**을 부드러운 곡선으로 만든다.
  - 혈압 140/90 이상(또는 약), 공복혈당 126·당화혈색소 6.5 이상(또는 약), 간 수치·지방간 지수(HSI) 높음, (선택) 중성지방 높음
- 여러 가지를 **같이** 움직여도 곡선에서 바로 값이 나온다. 진단 여부·혈압 입력 여부와 관계없이 누구에게나 나온다.
- 표현: "이런 체형·습관의 같은 또래 100명 중 몇 명" — 원인처럼 말하지 않는다.
- 방법: 기존 `analysis/extract.py` 흐름. 2022–23으로 만들고 2024로 확인. 저장소에는 집계표만.

> **2026-10-15 1단계 완료:** ① 곡선 분석과 ② 원문 확인 결과는 `docs/spec.md` §6-17에 기록했다(아래 표의 '확인 상태'는 모두 원문 확인됨). DPP 후속 분석의 "1kg당 10%"는 원문을 못 봐서 쓰지 않는다.

### 4-2. 연구에서 확인된 변화 (원문 확인 후 [확인] 표시)
| 바꾸는 것 | 알려진 변화 | 근거 | 확인 상태 |
|---|---|---|---|
| 몸무게 | 1kg당 수축기 약 1mmHg, 이완기 약 0.9mmHg 내려감 | Neter 2003 Hypertension (무작위 시험 25개) | 초록 확인 |
| 몸무게 (당뇨 진단 전) | 1kg당 당뇨 위험 약 10–16% 줄어듦 | Hamman 2006 Diabetes Care (DPP) + 후속 분석 | 초록 확인 |
| 몸무게 (당뇨 진단 후) | 1년 관해: 10–15kg 감량 57%, 15kg↑ 86% | Lean 2018 Lancet (DiRECT) | **2차 요약만 → 원문 확인 필요** |
| 술 (하루 2잔 초과) | 줄이면 혈압 내려감. 하루 6잔↑에서 절반으로 줄이면 수축기 약 5.5mmHg | Roerecke 2017 Lancet Public Health | 초록 확인 |
| 술 (한국인) | 과음에서 줄이면 암(특히 간암) 위험이 계속 과음보다 낮음 | Yoo 2022 JAMA Netw Open (건보공단 450만 명) | 초록 확인 |
| 몸무게 (지방간) | 10% 이상 감량에서 호전이 가장 큼 | Vilar-Gomez 2015 Gastroenterology | 초록 확인, 세부 % 원문 확인 필요 |
| 기존 10년 당뇨·4년 고혈압·10년 관상동맥 | 점수표 그대로 | Oh 2021, Lim 2013, Jee 2014 | [확인] → '더 보기'로 |

- 사람마다 해당하는 근거만 고른다(예: 진단 전/후, 술 마시는 양에 따라).
- 연구 범위 밖으로 곱해서 늘리지 않는다. 개인에게 단정하지 않고 "연구에서는 평균"으로 쓴다.

## 5. 새 결과 화면 틀 (모든 사람 공통)

```
┌ [누구] · 나이 성별 ─────────────── [공유] ┐
│ 한 줄 결론                                 │
│ 당뇨    [또래 대비 막대] 한 단어   이유 칩 2개 │
│ 고혈압  [또래 대비 막대] 한 단어   이유 칩 2개 │
│ 지방간  [또래 대비 막대] 한 단어   이유 칩 2개 │
│   (줄을 누르면 점수표·점 100개·근거)          │
│ 할 일: 한 줄                                │
└────────────────────────────────────────────┘
┌ 이렇게 바꾸면? ─────────────────────────────┐
│ 몸무게 · 허리 · 술 · 담배 · 운동 (해당하는 것만) │
│ 빠른 버튼: "5% 빼기" "허리 2인치" "술 반으로" 등 │
│ → 나 같은 한국인 100명 중 (그림이 바뀜)        │
│ → 연구에서 확인된 변화 한두 줄                  │
└────────────────────────────────────────────┘
[검진표 풀이] [진료용 요약] [모든 항목]
```

- **줄 하나의 규칙 (상태별):**
  | 상태 | 막대 | 한 단어 | 이유 칩 |
  |---|---|---|---|
  | 가능성 숫자 있음 | 또래 대비 위치 | 낮은 편 / 비슷 / 높은 편 / 매우 높음 | 점수 큰 항목 2개 |
  | 진단받아 관리 중 | 회색 | 관리 중 | 관리 포인트 1개 (예: 매년 눈·콩팥 검사) |
  | 검진 수치 기준 이상 | 빨강 | 확인 필요 | 수치 |
  | 술 때문에 계산 제외 | 빨강 | 간 검사 필요 | 주당 술 양 |
  | 허리 몰라 범위 | 범위 막대 | 범위 | "허리 넣으면 정확" |
  | 계산 대상 아님 (나이 등) | 없음 | 대상 아님 | 이유 |
- **순위 문구:** 높은 쪽 20% 안에서만 "몇 번째로 높아요". 가운데는 "또래와 비슷해요". 빨강은 높을 때만.
- **할 일:** 지금 판정 규칙(`verdict.ts`)의 우선순위 그대로, 한 줄로.

## 6. 가족·공유

- 입력 첫 화면 "누구 걸 볼까요? 나 / 배우자·애인 / 엄마 / 아빠 / 형제·자매 / 친구" → 결과 문구의 주어가 바뀐다. 기록에 이름표(이 기기 안에만).
- 카톡 공유 카드: 기기 안에서 요약 이미지를 만들어 보낸다. 받는 사람은 "나도 1분 해보기"로 들어온다.
- "병원에서 이렇게 말하세요" 한 줄 + 기존 진료용 요약.

## 7. 점검 방법 (사람 몇 명이 아니라 전수)

- 가상 인물 수백 명: 나이 19–80, 남녀, BMI·허리 전 구간, 술·담배·운동 모든 경우, 진단 조합, 허리·혈압 모름, 검진 수치 있음/없음.
- 확인할 것:
  - 맨 위가 비거나 엉뚱한 사람이 없는가
  - 세 줄이 모든 상태에서 같은 모양으로 나오는가
  - 순위·색·문구가 서로 맞는가
  - 바꿔보기에서 아무것도 안 바뀌는 사람이 없는가
  - 금지어(119·응급 등)가 나오지 않는가
- 기존 정답지(`tiers.cases.ts` 56명)와 `analysis/scenarios/user200.ts`를 넓혀서 쓴다.
- 마지막에 40–50대 실제 사용자 몇 명에게 "가족에게 보여줄 수 있겠어요?"를 확인한다.

## 8. 진행 순서

1. 4-1 데이터 분석 + 4-2 원문 확인 → `docs/spec.md` 새 절
2. 결과 틀 시안 (5장의 규칙이 모든 상태에서 어떻게 보이는지 한 장에 모아서)
3. 구현: 새 파일로 추가, 엔진 계산식은 그대로, 전수 점검 테스트
4. 가족 선택·공유 카드
5. 사용자 확인

## 9. 정할 것

1. 공유: 결과 이미지 + 앱 주소만 / 받는 사람이 같은 결과 화면을 열 수 있게 링크에 숫자를 담기
2. 작업 폴더: v3(체형 캐릭터 + 글래스) 기준인지
3. '나 같은 한국인' 항목: 혈압·혈당·간 수치 세 개로 시작할지, 중성지방까지 넣을지
