# jeton.com 메인 분석 (다시, 2026-10-08)

방법: 헤드리스 크롬 1440×900, 60px씩 스크롤하며 프레임 104장 + 프레임마다 요소 위치·변형·투명도 기록, `position: sticky` 구조 측정. 규제 안내 팝업은 누르지 않고 캡처에서만 지움.
이전 분석의 잘못: 700px 간격 정지 사진이라 **움직이는 도중의 크기·위치를 원래 디자인으로 착각**했고, 화면이 붙잡힌 채 스크롤로 장면이 바뀌는 연출을 놓쳤다.

## 1분체크로 옮기기 (장면별)
1. 첫 화면: 꽉 찬 3D 이미지(A) + 왼쪽 아래 '내 몸이 궁금할 때 딱 1분.' + 오른쪽 아래 설명·두 버튼. 내리면 흰 장면이 덮음
2. 붙잡힌 '숫자 몇 개면 충분해요': 실제 앱 조각(BMI 칩, 100명 점, 검진 카드, '만약 줄이면?' 판) + 사진(D) 조각이 바깥에서 모여듦
3. 붙잡힌 낱말: '또래 중 나' → '줄이면?' → '검진 풀이' 하나씩, 마지막에 겹쳐 쌓임
4. 초록이 차오르는 띠: '숫자 4개' → '10초면' 글 바뀜 + 미니 체험 카드, 이어서 휴대폰 + 01–05 단계(단계마다 실제 앱 화면)
5. 원형 이미지(B) 확대 → 가운데 휴대폰(결과 카드 3장) + '내 결과, 카드 3장으로.'
6. '또래 중 몇 번째? 확인.' 문장 + 3D 오브젝트(C)가 커지며 '이대로면 vs 바꾸면' 실제 판
7. 100명 점이 가운데에서 흩어지며 '100명 중 나는 몇 번째?' 카드가 드러남
8. 사진(D) 위 유리 카드: 후기 대신 '이럴 때 써요' 장면 셋(검진표 받은 날 · TV 보다가 · 단톡방 링크)
9. 비스듬한 초록 띠 + '1분이면, 내 몸이 보여요.'
10. 바닥글 + 화면 폭 가득 '1분체크'
도구: Lenis(부드러운 스크롤) + motion(React, 스크롤 진행도로 위치·크기·투명도). 움직임 줄이기 설정이면 정지 화면.
검증: 같은 스크롤 간격으로 jeton 프레임과 나란히 캡처해 장면마다 비교한 뒤 보여준다.
