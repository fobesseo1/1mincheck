## 3. 시나리오 만들기 (수백 개, 아주 다양하게)
두 가지 방식을 모두 써.
A. 가상 프로필 격자: 아래 축을 조합해 수백 개 프로필을 만들고, 원시자료에서 같은 조건(칸)에 해당하는 실제 사람들의 가중 실측 비율과 비교.
   - 나이(20대~70세↑), 성별, BMI(저체중·정상·비만전단계·1·2단계), 허리(복부비만 여부, 허리/키 0.5·0.6 경계), 흡연(안 피움·과거·현재), 음주(안 마심·월 몇 번·주 1–2·주 3–4·거의 매일 × 한 번 양), 운동, 폐경, 당뇨 가족력, 진단(고혈압·당뇨·고지혈증 조합), 혈압 범주(모름·정상·주의·높음)
B. 실제 응답자 재현: 원시자료의 각 성인을 그대로 앱 입력으로 바꿔 계산하고, 결과를 시나리오 칸별로 묶어 비교.

그리고 "검진 수치 입력" 상황을 단계별로 반드시 나눠서 돌려:
   1) 기본: 검진 수치 없음, 혈압 '모름'
   2) 혈압 범주만 앎 (실측 혈압으로 정상/주의/높음 선택)
   3) 혈압 숫자 입력 (실측 수축기/이완기)
   4) 공복혈당만 입력
   5) 혈압 + 공복혈당
   6) 전체 검진: 혈압·공복혈당·총콜레스테롤·중성지방·HDL·eGFR(크레아티닌으로 CKD-EPI 2021 계산)·요단백(HE_Upro → 음성/±/1+/2+이상)
   7) 일부만 (예: 콜레스테롤 3종만, eGFR·요단백만)
   8) 오래되거나 부정확한 수치 (실측에 ±10–20% 오차, 1년 전 값 가정) → 앱 판정이 얼마나 흔들리는지
   9) 경계값 근처 (공복혈당 99–101·125–127, 혈압 129/84–131/86, 총콜레스테롤 238–242, eGFR 58–62)
   가능하면 음주 원답(소주·맥주·와인 종류별 양)이 있는 경우와 없는 경우도 나눠.

## 4. 비교할 것
- 확률 항목(보정값): 당뇨(진단받지 않은 사람 중 공복혈당 126↑ 또는 당화혈색소 6.5↑), 고혈압, 고콜레스테롤, 골다공증 → 칸별 예측 평균 vs 실측, 가중 AUC, Brier, 보정 그래프(10분위).
- 판정·안내: 앱이 "먼저 확인할 것"·"또래보다 높음"에 넣는지 vs 실제로 해당 질환이 있는지 → 민감도·특이도·양성예측도. 특히 "또래와 비슷/낮음이라고 했는데 실제로는 양성"인 비율(놓침)과 "높다고 했는데 음성"(헛경보).
- 추가 체크 카드: 대사증후군(앱 판정 vs 실측 5개 기준), 콩팥(앱 점수·안내 vs eGFR<60 또는 요단백 1+), 고위험음주(앱 vs 이용지침서 dr_high), 체형·허리/키, 생활습관 위험, 치매 위험요인 개수 분포.
- 검진 수치를 넣을수록 판정이 얼마나 좋아지는지(1→6 단계별 개선폭).
- 우울은 확률이 아니라 PHQ 점수라 비교 제외. 지방간은 초음파 실측이 없으니, 하려면 대리지표(예: 간지방지수 HSI)로 "참고"로만.

  4) 검진 수치 단계별 개선 효과
  5) 놓침·헛경보가 큰 안내 문구/판정
  6) 개선 제안 (우선순위, 기대 효과, 근거 숫자, 엔진·보정·화면 중 어디를 고쳐야 하는지, 위험)
